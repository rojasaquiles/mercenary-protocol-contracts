# 🛡️ Web3 Game Economy & DeFi Smart Contracts Core

Un ecosistema de contratos inteligentes en Solidity altamente optimizado, modular y seguro, diseñado para servir como el backend económico y de gobernanza para un juego Web3 on-chain. 

El proyecto implementa un modelo económico deflacionario, bóvedas de seguridad (*Vaults*), tokens actualizables mediante patrones proxy UUPS de OpenZeppelin, y está respaldado por una suite exhaustiva de pruebas unitarias, de fuzzing y de invariantes de alta exigencia (con más de 128,000 llamadas de estrés).

---

## 🏗️ Arquitectura del Sistema

El sistema utiliza la librería de contratos actualizables de OpenZeppelin y se divide en los siguientes componentes principales:

1. **`MyGameToken.sol` (Token ERC20 Upgradable):**
   * Token base del juego con soporte para UUPS Proxy.
   * Sistema de control de minteo y permisos de quema (*Burner Role*) otorgados al gestor económico.
2. **`GameTokenVault.sol` (Tesorería / Vault):**
   * Contrato de custodia seguro para los fondos del juego.
   * Control estricto de depósitos y retiros autorizado exclusivamente para contratos de lógica aprobados.
3. **`GameEconomyManager.sol` (Gestor de Economía Deflacionaria):**
   * Centraliza la lógica de tarifas, comisiones e interacciones económicas del juego.
   * Aplica dinámicamente tasas configurables en *basis points* y ejecuta quemas o distribución a tesorería de forma automatizada.
4. **Módulos Adicionales de Juego (`EliteMercenary`, `BattlePass`, `GameItems`, `PVPPass`):**
   * Contratos para la gestión de NFTs, pases de batalla y activos del ecosistema.

---

## 🛠️ Stack Tecnológico
* **Lenguaje:** Solidity (`^0.8.24`)
* **Framework de Desarrollo:** Foundry
* **Patrones:** UUPS Proxies (OpenZeppelin Upgrades)
* **Pruebas:** Foundry Fuzzing, Invariant Testing & End-to-End Simulations

## 🚀 Guía de Inicio Rápido (Quick Start)

### Prerrequisitos
Asegúrate de tener instalado [Foundry](https://book.getfoundry.sh/getting-started/installation) en tu entorno (Linux/WSL/macOS).

### 1. Clonar e Instalar Dependencias
```bash
git clone <URL-DE-TU-REPOSITORIO>
cd <NOMBRE-DEL-PROYECTO>
forge install   

2. Compilar los Contratos
forge compile

3. Ejecutar la Suite de Pruebas

forge test -vvv

ejecutar las pruebas de invariantes de alta intensidad:

forge test --match-contract GameInvariants -vvv

📦 Despliegue Automatizado
El repositorio incluye un script maestro de despliegue en Solidity utilizando Foundry (script/Deploy.s.sol), el cual automatiza el despliegue de las implementaciones, la creación de los Proxies UUPS, la inicialización y el enlazado de permisos (como el rol de burner).

Para simular el despliegue en local (Anvil):

Bash


forge script script/Deploy.s.sol --rpc-url [http://127.0.0.1:8545](http://127.0.0.1:8545) --broadcast
Para desplegar en una red de prueba (Ej: Sepolia), configura tus variables de entorno en un archivo .env (PRIVATE_KEY, RPC_URL) y ejecuta:

Bash


source .env
forge script script/Deploy.s.sol --rpc-url $RPC_URL --private-key $PRIVATE_KEY --broadcast --verify
